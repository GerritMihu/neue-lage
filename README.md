# Neue Lage

Countdown der verbleibenden Studientage (Mo–Do) bis Ende Wintersemester 31.01.2027.

Live: https://gerritmihu.github.io/neue-lage/

## Freie Tage ergänzen

In `index.html` das Array `FREIE_TAGE` erweitern (Einzeltag `'YYYY-MM-DD'` oder Bereich `['von', 'bis']`) und pushen.
Die gleiche Liste gibt es lokal für den Conky in `~/.config/conky/freie_tage.txt`. Bitte beide aktuell halten.
